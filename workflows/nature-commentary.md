# Workflow recipe: nature-commentary

**Not a Skill.** For a short, high-profile commentary/opinion piece (e.g. in
the style of a *Nature*/*Science* commentary), not a full research article.

## When to select this recipe

Trigger example: "Write a Nature-style commentary on X."

## Stages

```
scholarly-corpus-builder: bounded evidence
  (a handful of load-bearing, current sources -- not a full literature
   corpus; commentaries are argument-dense and evidence-sparse by genre)
  |
  v
scholarly-voice-engine: commentary mode
  (commentary-writing genre policy, not research-article structure)
  |
  v
evidence/claim audit
  (every claim in a short, high-visibility piece must be individually
   checkable -- no claim should ride on unstated background assumption)
```

## Explicit non-goal

Avoid journal-article style (IMRaD structure, dense methods section) unless
the target venue specifically calls for it (rule 25). Keep the corpus request
bounded -- this is the clearest case where a full corpus build would be
wasted context relative to the deliverable (rule 50, rule 52).
